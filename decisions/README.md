# 决策记录 (ADR)

每个非平凡改动记录一条决策，说明**为什么这么做**，而不是做了什么。

## 格式

文件名：`NNNN-短标题.md`，NNNN 为递增编号。

```markdown
# NNNN: 决策标题

- 状态：已采纳 / 已废弃 / 待修订
- 日期：YYYY-MM-DD
- 相关文件：path/to/file.py

## 背景
描述问题和约束。

## 决策
具体选了什么方案。

## 理由
为什么选这个，不选别的。

## 后果
正面和负面的影响。
```
